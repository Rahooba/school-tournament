# 🏆 دوري المدرسة — Next.js + Supabase

كرة القدم (فوز 3 / تعادل 1 / خسارة 0) + الكرة الطائرة (فوز 3 / خسارة 0، مفيش تعادل).
كل فريق بيلاعب كل فريق مرة واحدة، وأول فريقين في الترتيب بيلعبوا النهائي.

## التشغيل
1. أنشئ مشروع على https://supabase.com
2. من **SQL Editor** شغّل محتوى `supabase/schema.sql` (مرة واحدة).
3. من **Authentication > Users** أضف مستخدم (إيميل + كلمة سر) — ده حساب المنظّم.
4. انسخ `.env.example` إلى `.env.local` وحط `Project URL` و `anon key` (Settings > API).
5. `npm install` ثم `npm run dev` (أو `npm run build && npm start`).
6. ادخل على `/admin` وابدأ: فرق ← إنشاء الجدول ← النتائج ← اللاعبين ← النهائي.

## النشر
أسهل حاجة Vercel: ارفع المشروع وضيف نفس الـ Environment Variables.

## ليه سريع؟
- الصفحات العامة ثابتة (ISR كل 30 ثانية + تتحدث فورًا عند أي تعديل من الأدمن) ومش بتستخدم كوكيز.
- الترتيب بيتحسب في قاعدة البيانات (View) مش بعدادات يدوية، فمفيش تضارب أرقام.
- Indexes على الجداول، وصور بتتحسّن تلقائيًا (WebP/AVIF) من Supabase Storage.
- مفيش فيديوهات خلفية (كانت 40MB في النسخة القديمة) ولا مكتبات UI تقيلة، وJS صغير جدًا.
